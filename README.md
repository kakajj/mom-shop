# MomShop V1.8.1 — Inventory & Sales

อัปเกรดจาก V1.7: สำรอง JSON ก่อน แล้วแทนไฟล์ทั้ง 8 ไฟล์บน GitHub Pages repository เดิม ใช้ URL และ browser เดิม เปิดออนไลน์ให้ service worker อัปเดต แล้วปิดเปิดอีกครั้ง อย่าล้างข้อมูลเว็บไซต์

## วิธีใช้
- คลังสินค้า: เพิ่มชื่อ รูป หมวดหมู่ ราคาปกติ ยอดยกมา และทุนถ้าทราบ สินค้าเดิมต้องตั้งยอดจริงก่อนขาย ไม่หักยอดขายในอดีตซ้ำ
- เติมสต๊อก: กรอกจำนวนและราคารวมหรือราคาต่อชิ้น แต่ละครั้งราคาเปลี่ยนได้ เลือกบันทึกเงินจ่ายเมื่อจ่ายจริง ทุนเฉลี่ยคำนวณจากของที่เหลือและของที่เติม หากไม่ทราบทุนระบบไม่แสดงกำไรเป็นตัวเลขครบถ้วน
- ขาย: เลือกสินค้า จำนวน ราคาต่อชิ้นหรือราคาเหมา ขายหลายสินค้าจากปุ่มขายหลายสินค้า หักคลังอัตโนมัติ ไม่ให้ติดลบ
- ลบจากรายการโดยตรง คืนสินค้าเมื่อยกเลิกยอดขายที่เชื่อมคลัง ประวัติเดิมไม่คืนสต๊อกเพราะเกิดก่อนตั้งยอด
- แก้จำนวนหรือชนิดสินค้า: คืนสินค้าด้วยต้นทุนเดิมก่อนบันทึกใหม่ด้วยทุนเฉลี่ยปัจจุบัน การแก้เฉพาะราคาคงต้นทุนเดิมไว้ ไม่คำนวณย้อนหลังทุก movement
- ตรวจนับ / เสียหาย: เปิดประวัติสินค้าแล้วเลือก action ที่ต้องการ ประวัติบันทึกตามเวลาทำรายการ การปรับจำนวนไม่เปลี่ยนยอดขาย
- รายงาน: รายวัน สัปดาห์ เดือน แยกเงินรับสุทธิจากกำไรที่บันทึก; ไม่หักค่าซื้อสต๊อกซ้ำ กำไรไม่รวมการตีราคาสินค้าเสียหายหรือภาษี
- แชร์: Native Web Share API ส่ง plain text เท่านั้น เลือกแอปจากมือถือ ไม่มีการสร้างภาพหรือคัดลอกอัตโนมัติ หากไม่รองรับจะแจ้งเตือน
- สำรอง: JSON version 2 มีสต๊อกและประวัติ รองรับ import version 1; CSV สำหรับยอดขาย/รายจ่าย ไม่ใช่ backup ครบถ้วน

## ข้อจำกัด
ข้อมูลอยู่ใน IndexedDB เครื่องเดิม ไม่มี sync หรือ backend; ใช้ทีละแท็บเพื่อหลีกเลี่ยงการเขียนทับจากหลายแท็บ; สำรองสม่ำเสมอ. ราคาทุนที่ไม่ทราบยังคงไม่ทราบจนสต๊อกเดิมหมดแล้วรับเข้าด้วยทุนที่ทราบ. ไม่มีระบบบัญชีเต็มรูปแบบหรือการย้อนคำนวณต้นทุนตามวันที่ย้อนหลัง. หมวดหมู่เพิ่มได้ แต่ยังไม่มีลบ/เปลี่ยนชื่อ. รายจ่ายที่เชื่อมการซื้อเป็นการบันทึกเงินจ่ายแยกจากสต๊อก การลบรายจ่ายไม่ลบของที่รับเข้า. ทดสอบ syntax และ logic หลักด้วย Node; ยังไม่ได้ทดสอบ browser/iOS/Android หรือ Messenger จริง.

## V1.8.1 — รีเฟรชแอป
- ปุ่มรีเฟรชข้างชื่อร้าน ใช้ได้ทุกหน้ารวมถึง PWA แบบ standalone
- เมื่อออนไลน์จะพยายามตรวจสอบ Service Worker รุ่นใหม่ก่อนโหลดหน้าอีกครั้ง หากออฟไลน์หรือเช็กไม่สำเร็จจะโหลดรุ่นที่เก็บไว้
- ไม่ลบ IndexedDB, localStorage หรือข้อมูลสินค้า ไม่ใช่ปุ่มล้างข้อมูล
- หากกำลังบันทึกหรือเปิดฟอร์มอยู่ ให้ทำรายการให้เสร็จก่อน
- รีเฟรชแล้วกลับหน้าหลักตามพฤติกรรมเดิม ไม่เก็บตัวกรองชั่วคราว
- อัปเดตครั้งแรกจาก V1.8 อาจต้องปิดและเปิด PWA ใหม่ขณะออนไลน์เพื่อให้ Service Worker ใหม่ทำงาน
- ยังไม่ได้ทดสอบบนมือถือจริง
