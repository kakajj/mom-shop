# MomShop v1.0
เว็บสมุดขายของแม่ ภาษาไทย Mobile-first ไม่มี Backend

## ติดตั้ง GitHub Pages
1. สร้าง repository ใหม่ เช่น mom-shop
2. แตก ZIP แล้วอัปโหลดไฟล์ทั้งหมดจากโฟลเดอร์นี้ไว้ที่ root ของ repository (ไม่ต้องสร้างโฟลเดอร์ซ้อน)
3. Settings > Pages > Deploy from a branch > main > /(root) > Save
4. เปิด URL ที่ GitHub Pages แสดงให้ จาก Safari หรือ Chrome
5. เพิ่มเว็บไซต์ลงหน้าจอหลักจากเมนูเบราว์เซอร์

## ใช้งาน
- วันนี้: บันทึกขายหรือรายจ่าย (พิมพ์สินค้าเองได้), แตะ ⋮ เพื่อแก้ไข/ลบ
- สินค้า: เพิ่มชื่อ ราคา รูป และกดขายจากรายการสินค้า
- ย้อนหลัง: เลือกวันหรือเดือน
- ตั้งค่า: ดาวน์โหลด JSON สำรองข้อมูลพร้อมรูป, กู้คืน (แทนที่ข้อมูลเดิม), CSV สำหรับ Excel
- แชร์ยอด: ใช้เมนูแชร์ของเครื่องหรือคัดลอกข้อความไป LINE

## ข้อจำกัด
ข้อมูลอยู่ใน IndexedDB ของเบราว์เซอร์และ origin ปัจจุบัน ไม่ได้ส่งไป GitHub หรือซิงก์ข้ามเครื่อง ให้สำรอง JSON เป็นประจำ การเปลี่ยน URL หรือเปิดผ่านเบราว์เซอร์อื่นอาจเห็นฐานข้อมูลว่าง เงินคงเหลือคือยอดขายหักรายจ่ายที่บันทึก ไม่ใช่กำไรสุทธิหากไม่ได้บันทึกต้นทุน

ใช้ HTML, Vanilla JS, native IndexedDB, Canvas ย่อรูป และ CSS ที่อยู่ใน repo เอง โดยมี Tailwind Browser CDN เป็นตัวเสริม ไม่จำเป็นต่อฟังก์ชันหลัก ไม่ได้ใช้ Dexie, Chart.js หรือ SweetAlert2 เพื่อให้การทำงานไม่ผูกกับ CDN ตัวอื่น Service Worker เตรียมไว้สำหรับ offline หลัง cache สำเร็จ แต่ต้องทดสอบบน HTTPS และมือถือจริงก่อนใช้งานจริง

ตรวจสอบ syntax JavaScript แล้ว แต่ environment ทดสอบบล็อกการเปิดหน้าเว็บใน Chromium จึงยังไม่ได้ยืนยัน end-to-end, PWA, LINE sharing หรือการทำงานบนมือถือจริง
