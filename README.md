# MomShop v1.6
เว็บสมุดขายของแม่ ภาษาไทย Mobile-first ไม่มี Backend

## ติดตั้ง GitHub Pages
1. สร้าง repository ใหม่ เช่น mom-shop
2. แตก ZIP แล้วอัปโหลดไฟล์ทั้งหมดจากโฟลเดอร์นี้ไว้ที่ root ของ repository (ไม่ต้องสร้างโฟลเดอร์ซ้อน)
3. Settings > Pages > Deploy from a branch > main > /(root) > Save
4. เปิด URL ที่ GitHub Pages แสดงให้ จาก Safari หรือ Chrome
5. เพิ่มเว็บไซต์ลงหน้าจอหลักจากเมนูเบราว์เซอร์

## ใช้งาน
- วันนี้: บันทึกขายหรือรายจ่าย (พิมพ์สินค้าเองได้), แตะ ⋮ เพื่อแก้ไข/ลบ
- สินค้า: เพิ่มชื่อ ราคา รูป และกดขายจากรายการสินค้า
- ย้อนหลัง: เลือกวันหรือเดือน
- ตั้งค่า: ดาวน์โหลด JSON สำรองข้อมูลพร้อมรูป, กู้คืน (แทนที่ข้อมูลเดิม), CSV สำหรับ Excel
- แชร์ยอด: ใช้เมนูแชร์ของเครื่องหรือคัดลอกข้อความไป LINE

## ข้อจำกัด
ข้อมูลอยู่ใน IndexedDB ของเบราว์เซอร์และ origin ปัจจุบัน ไม่ได้ส่งไป GitHub หรือซิงก์ข้ามเครื่อง ให้สำรอง JSON เป็นประจำ การเปลี่ยน URL หรือเปิดผ่านเบราว์เซอร์อื่นอาจเห็นฐานข้อมูลว่าง เงินคงเหลือคือยอดขายหักรายจ่ายที่บันทึก ไม่ใช่กำไรสุทธิหากไม่ได้บันทึกต้นทุน

ใช้ HTML, Vanilla JS, native IndexedDB, Canvas ย่อรูป และ CSS ที่อยู่ใน repo เอง โดยมี Tailwind Browser CDN เป็นตัวเสริม ไม่จำเป็นต่อฟังก์ชันหลัก ไม่ได้ใช้ Dexie, Chart.js หรือ SweetAlert2 เพื่อให้การทำงานไม่ผูกกับ CDN ตัวอื่น Service Worker เตรียมไว้สำหรับ offline หลัง cache สำเร็จ แต่ต้องทดสอบบน HTTPS และมือถือจริงก่อนใช้งานจริง

ตรวจสอบ syntax JavaScript แล้ว แต่ environment ทดสอบบล็อกการเปิดหน้าเว็บใน Chromium จึงยังไม่ได้ยืนยัน end-to-end, PWA, LINE sharing หรือการทำงานบนมือถือจริง

## V1.5 — 26 พฤศจิกายน 2569
- ปรับ UI สีเขียวเข้ม/ครีม ปุ่มและไอคอนใหม่ รองรับหน้าจอเล็ก
- สรุปจำนวนชิ้นและจำนวนรายการขาย ค้นหาและกรองรายรับ/รายจ่าย
- ขายซ้ำจากประวัติ เลือกสินค้าและรายจ่ายด่วน ปุ่มเพิ่มลดจำนวน
- เลือกบันทึกสินค้าใหม่เข้ารายการสินค้าพร้อมบันทึกการขาย
- อันดับสินค้า 5 รายการตามยอดขาย ส่งออก CSV เฉพาะช่วงที่เลือก
- เปลี่ยนชื่อร้านได้ในตั้งค่า
- ใช้ฐานข้อมูล IndexedDB `momshop-v1` และ backup version 1 เดิม

### อัปเกรดจาก V1.0
สำรอง JSON ก่อน แล้วแทนที่ไฟล์ทั้งหมดใน repository เดิม (URL เดิม, browser/profile เดิม) ไม่ต้องลบข้อมูลเว็บไซต์ เปิดแอปออนไลน์และเปิดใหม่เพื่อรับ Service Worker ใหม่ หากใช้ URL/อุปกรณ์อื่นให้ Restore JSON จากเครื่องเก่า ไม่ควรลบข้อมูลเว็บไซต์เพื่อแก้ cache เพราะจะลบฐานข้อมูลด้วย

### การตรวจสอบ
ตรวจ JavaScript syntax และทดสอบฟังก์ชันคำนวณ/ข้อมูลสำรองแยกจาก UI แล้ว การเปิด Chromium ผ่าน localhost ถูกบล็อกโดยสภาพแวดล้อม จึงยังไม่ได้ทดสอบ UI end-to-end หรือทดสอบ iOS/Android จริง โปรดทดสอบก่อนใช้ข้อมูลจริง

## V1.6 — เสียงตอบรับ
- เปิดเสียงเป็นค่าเริ่มต้น (55%) มีเสียงขายสำเร็จ รายจ่าย บันทึกทั่วไป ลบ และข้อผิดพลาดแยกกัน
- ตั้งค่า > เสียงตอบรับ: เปิด/ปิด ปรับระดับเสียง ทดลองฟัง; ค่าจะอยู่ใน localStorage ของเครื่อง ไม่รวมใน backup ข้อมูล
- ใช้ Web Audio API ไม่ต้องโหลดเสียงหรือ CDN เพิ่ม เสียงเริ่มได้หลังผู้ใช้แตะหน้าจอ และอาจถูกจำกัดโดยเบราว์เซอร์หรือโหมดเงียบ
- ฐานข้อมูลและ backup schema เดิม; สำรองข้อมูลก่อนแทนที่ไฟล์ V1.5 ทั้งหมดใน repository เดิม เปิดออนไลน์และปิดเปิดแอปอีกครั้ง ไม่ล้างข้อมูลเว็บไซต์
- ตรวจสอบ JavaScript syntax และทดสอบการสร้างเสียงด้วย mock Web Audio; ยังไม่ได้ทดสอบเสียงจริงบนมือถือ
